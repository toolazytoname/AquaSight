# Web 阅读体验收尾验收

基线：`04d09db`。交付分支：`dev/web-reader-polish`。

## 改动

- 模型单价缺失或无效时，暂停新增请求；保留缓存摘要。每日 3.3 元、每月 100 元和每日候选上限继续生效，状态接口报告暂停原因。
- 收藏用本机快照和带版本的待同步意图保存，取消收藏也持久化。启动、联网恢复、手动刷新重试；过期请求不能覆盖新操作。静态页只保存在本机。
- 阅读列最大 720px，桌面导航 176px；手机主题常驻、来源展开、支持清除筛选。详情收藏不重置滚动。设置支持三种主题、来源勾选、焦点约束和 Escape。
- 搜索和导航通过请求代次忽略旧响应。未读过滤叠加本机阅读状态。Service Worker 壳版本升级到 v7，保留个人数据。

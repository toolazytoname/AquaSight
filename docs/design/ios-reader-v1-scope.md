# iOS 个人阅读器 v1 · 已实现范围

日期：2026-09-28。状态：本地实现与验证完成，后端尚未部署。详细证据见[改版验收报告](../reviews/ios-reader-2026-09-28.md)。

## 产品与 UI / UE

- iOS 导航为「阅读 / 订阅 / 收藏」。首次启动展示选源引导，空选择返回空阅读流，不自动回退全站。
- 订阅按「开源项目 / 技术与研究」分组，支持快捷选择、逐项选择、保存与还原；固定操作区显示选中数量。
- 默认可选 GitHub 四个入口、OpenAI 和 Hugging Face。阅读保留搜索、分页、原文、AI 整理及离线收藏。
- 大屏限制内容宽度，支持深色和大字号，保留明确的加载、空内容、失败重试和未同步反馈。
- 网页个人设置新增「个人订阅」，登录用户可打开「显示更多信息源」后逐项选择。默认关闭，关闭保留选择与收藏，不自动开启通知或早报。

## 实现与同步

偏好存储在用户设置的独立 `reader` 对象中：`selectedSources`、`moreSourcesEnabled`、`configured`。专用 `/api/v1/reader/catalog` 和 `/api/v1/reader/settings` 提供目录与设置；`/api/v1/events?view=reader` 和详情的 `reader=1` 使用独立阅读范围。更新按字段原子合并，iOS 仅写所选来源。

游客基础来源选择保存在本机；登录已有账户以服务器选择为准，首次配置的新账户可带入游客选择。登录后的离线修改待联网重试。缓存按账户与有效来源集合隔离，取消订阅后私人收藏仍可阅读。新接口显式返回能力标记，旧后端不会被误认为支持个人订阅。

新阅读查询不受旧网页 blockedSources 偏好影响。现有网站阅读、共享采集和早报行为保持原有语义。Service Worker 不缓存私人订阅接口。来源须在目录中，原文为无嵌入凭据的 HTTP(S) 地址；隐藏条目不进入阅读流。

## 保留范围

本轮未新增任意 RSS、社区、分享或客户端模型调用。继续复用既有 AI 翻译、摘要与去重管线，客户端不持有模型密钥。

这是公开的用户偏好设置，所有用户使用相同功能和默认值。商店描述与审核材料应覆盖实际功能；功能改版不代表已完成上架材料或取得发行资格。

## 审核说明（随实际发布状态核对后填写）

鸭先知是个人订阅与阅读工具，主界面包含阅读、订阅和收藏。无需登录即可选择基础来源、阅读并保存本机收藏。首次使用请进入订阅页，选择来源并保存；阅读页可进入详情、查看 AI 整理与原始链接。

账户使用邮箱和密码登录。注册、忘记密码或原验证码账户首次设置密码时，通过邮箱验证码验证本人；默认登录不要求每次收邮件。登录用于跨设备同步订阅、收藏及阅读记录。网页 `https://quack.weichao.ren/#/reader-settings` 提供账户级“显示更多信息源”设置，默认关闭，开启后由用户逐项选择；关闭保留选择及私人收藏。这是所有用户可用的普通偏好设置。

删除账户：收藏 → 右上角账户 → 删除账户数据 → 确认。该操作删除服务器账户、密码凭据、全部会话及个人同步数据，同时清除当前设备上该账户的数据。其他设备收到会话失效后需重新登录，离线副本无法远程清除。

AI 概述仅辅助阅读，界面提供原始来源。没有应用内购买、广告追踪或原生推送。请勿将 DEBUG 测试验证码或测试服务当成正式审核登录方式。

## 隐私问卷准备

无跨应用跟踪、无广告用途。登录时邮箱、账户标识、会话安全信息与账户关联，用于应用功能及安全；已读记录、收藏快照、订阅选择与账户关联，用于跨端同步。密码只保存加盐慢哈希。按照 Apple 实际问卷分类逐项核实并发布答案。

隐私政策：`https://quack.weichao.ren/privacy.html`。第三方包括 Cloudflare 托管与邮件服务；模型只接收公开来源文本，不接收用户密码、邮箱或私人收藏。

## 截图与构建

工程验收截图在 `docs/reviews/ios-password-2026-09-28/`。XR 截图不是所有商店规格，最终上传需从对应尺寸设备生成，无测试账号/验证码/调试错误。不得把本地测试数据的截图描述为实时生产内容。

新密码接口必须先执行 `worker/migrations/20260928_password_auth.sql`，再部署 Worker 和网页；迁移仅新增表、可重复执行。发布工作流已加入此顺序。旧客户端验证码接口保留兼容。

密码 scrypt 在本地 workerd 运行成功；一组生成/正确校验/错误校验约 412 ms（本机时点）。部署前需确认生产 Worker CPU 套餐/限额可承担慢哈希并实测，不以降低密码哈希强度规避资源限制。已读回 Worker 使用 standard 模式；当前授权令牌无法读取付费订阅或确认具体 CPU 配额，未更改套餐。

## 配套发布与回滚

- `npm run deploy` 现在明确针对 production，先执行可重复的新增表迁移，再发布；`npm run deploy:staging` 同样先迁移对应 staging 数据库。上述命令本轮均未执行。
- 发布工作流仍需手动触发，不因代码修改自动上线。发布前完整 Node 测试通过后再执行迁移；生产密码登录需部署后用专用测试账户验证，不操作个人账户删除。
- 新增表不会修改既有收藏与订阅。若回滚 Worker，可保留新增表；不要删除密码凭据或恢复旧明文登录材料。
- 用户当前真实账户仍未设置密码。本轮未替用户生成或更换私人密码；首次设置应由用户在发布后的正常验证流程完成。

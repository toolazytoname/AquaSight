# 鸭先知 Ponder · UI 交付稿

设计日期：2026-09-22。范围：阅读产品的高保真界面与交互参考。正式 `web/`、后端、数据库均未改动。

## 怎么看

- 双击 `index.html` 可离线打开交互原型；不依赖 npm、CDN、字体下载或图片服务。
- `gallery.html` 是截图总览，适合与实现结果并排对照。
- `screens/` 是浏览器实际渲染截图，不是生成图片。
- 启动本地预览：在此目录运行 `python3 -m http.server 8876 --bind 127.0.0.1`，打开 `http://127.0.0.1:8876/`。
- 手机请将视口设为 390×844，桌面为 1440×1000；另外检查 768px 平板和 320px 窄屏。

页面路由：`#featured` 精选、`#latest` 最新、`#digest` 早报、`#saved` 收藏、`#event/agent` 详情。`?theme=dark#featured` 直接打开深色稿。

## 设计取舍

阅读优先，以中文标题、摘要和来源建立层级。保留深绿品牌，用中性背景与黑色正文承载大部分信息。所有条目保持可扫读的单列，精选首条增加字号与留白，早报有独立刊期、综述与章节。

正文没有装饰图片是有意选择：新闻事件多样，不能把无信息量的配图或生成图放在阅读之前。将来有可信、必要的图表或原始图像时，按内容需要插入详情，不给每条卡片强制留图片位。

顶端“设计预览”细条是原型标记，正式产品移除。正文中的示例声明同样不直接复制到正式 UI。原型文章经过改写，时间、状态、收藏均为展示数据，不是新的事实核验或真实后台结果。

## 逐页实现要求

### 精选

- 页面标题、一句说明、主题切换、一个筛选入口。
- 重点条目与普通条目有级差，所有条目结构一致。
- 每条只显示一个主标题、一段摘要、一行来源时间；不重复摊开英文原题和 AI 要点。
- 收藏按钮始终可点，实心表示已收藏；不依赖 hover 才出现。
- 原型首条是固定示例；生产要由编辑或明确的质量规则确定重点，不能盲选数组第一条。
- 原型仅 6 条供观察，正式精选数量根据实际质量决定，不用占位内容凑满。

### 最新

- 时间分组、更紧凑的标题列表。保留来源时间。
- 原型搜索匹配整个示例集合。正式搜索需要明确范围，并用真实后端分页。
- 缺乏可靠发布时间时显示发现时间，不用采集时间冒充发布时间。

### 详情

- 返回入口保留来源列表；原型提供滚动恢复。
- 导语 → 真正新增的事实 → 背景 → 来源。没有内容的小节不占位。
- “放在背景里看”属于分析，与事实区分；生产需真实引用和生成来源标识。
- 来源可点击，原题折叠。部分示例链接指向媒体首页，正式必须改为具体文章链接。
- 不把单来源包装为独立交叉验证。
- 收藏、来源和分享在正文前即可访问，底部继续阅读下一条。

### 早报

- 自成一期：上方实线、日期、问候标题、简短综述、报道窗口、分类条目、读完状态。
- 不复用首页的一整排筛选器。
- 概述最长不超过原型的体量，没有可靠综述时省略。
- 历史期次在原型中明确未接入；正式无历史数据就隐藏该入口。

### 收藏

- 已存篇数、保存位置和登录同步入口。
- 默认两条示例，列表收藏与收藏页联动，支持取消和撤销。
- 正式需接回现有快照、离线队列、墓碑与跨端合并，不能照搬原型的内存 Set。
- 私人添加链接放这里，不占全局导航，不写入公共新闻池。

### 设置与登录

- 设置按照外观、内容来源、账户与同步拆开。
- 外观真实切换；源开关只演示控件状态，不对示例数据执行持久化。
- 登录提供邮箱和验证码两阶段版式，显式声明不发信、不登录。
- 正式需补真实倒计时、错误、重试、提交锁和投递状态，不能把演示结束按钮当登录成功。
- 弹层使用原生 dialog，支持 Escape、背景点击关闭与焦点回还。

## 已实现与刻意留作示例的边界

| 操作 | 原型行为 |
| --- | --- |
| 五种页面及新闻详情 | 可导航 |
| 分类和来源筛选 | 过滤内存示例 |
| 搜索 | 匹配标题、摘要、媒体；支持 `/` 快捷键 |
| 收藏 / 取消 / 撤销 | 同一次打开的内存状态联动，刷新恢复样本 |
| 浅色 / 深色 | 可切换；URL 也能指定 |
| 分享 | 复制当前原型 URL，无法复制时选中链接 |
| 原文 | 外部真实媒体域名，部分为文章链接、部分为首页 |
| 登录、添加链接、反馈、来源偏好 | 流程/状态演示，不发送网络请求 |
| 往期早报 | 明确显示只有示例刊期，不伪造历史数据 |
| 离线 | 设置中可预览提示，不模拟实际 Service Worker |

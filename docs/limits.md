# 免费额度与超额

正式环境：Cloudflare Workers 托管网页和 API，D1 存数据。采集仍在 GitHub Actions。

## Cloudflare Workers Free（2026）

- 每天约 10 万次 Worker 请求；超额后当天请求失败，UTC 零点恢复。
- CPU 时间很短。聚类和模型调用必须留在 Actions / 本机 Node，不要放进 Worker。

## D1 Free（2026-09 起按日强制）

- 每天 500 万行读取、10 万行写入。超额后查询失败，数据仍在，UTC 零点恢复。
- 账号总存储约 5 GB，单库免费上限 500 MB。
- Cloudflare 会在额度打满时发邮件。看板：D1 查询次数与存储。

超额处理：Worker 把 D1 错误映射为 `503` + `error: quota`。客户端继续读本机缓存。不要在高峰全表扫描 `events`。

## GitHub Actions

- 公开仓库免费分钟数通常够定时采集。私有仓另计。
- 采集失败时站点应继续展示上次 D1 / `events.json` 快照。

## 邮件（Resend 免费档）

Cloudflare 托管网页不等于能发验证码。当前适配 Resend：

- 约每天 100 封、每月 3000 封。
- 正式发信必须验证自己的域名（DNS：SPF/DKIM）。未验证时只能把测试信发给 Resend 账号邮箱。
- 域名本身可能产生注册费；这与 Cloudflare 免费子域名分开。
- 应用层限额：每邮箱每小时 5 封、每天 12 封；每 IP 每小时 10 封；全局每天 80 封，给平台额度留余量。

国内邮箱（QQ / 163 / 阿里云）投递取决于发件域名声誉，上线前必须用这些邮箱实测。本仓库无法代替国内拨测。

## 模型费用

整理走 Actions 里的中转或 xAI。单价未配置时不得新增付费请求。每月 100 元、每天 3.3 元、每天候选上限仍有效（仅在单价已知时硬限制）。

## 客户端分发

- iOS 正式分发通常需要 Apple Developer 会员。
- 安卓商店上架也可能有平台费用。
- 这些与 Cloudflare 免费托管分开核算。
